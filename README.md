# ETL-fsharp-project

F# ETL pipeline that reads order data from CSV (local or HTTP), applies filters, joins orders with items, computes order totals and monthly averages, and writes results to CSV (and optionally to SQLite).

## Requirements
- .NET SDK (target net10.0)

## Project Structure
- DataIn/: input CSVs (order.csv, order_item.csv)
- DataOut/: generated outputs (order_totals.csv, totals_by_month_year.csv, etl.db)
- ETL/: pure functions and domain types
- Main/: console app that orchestrates the pipeline
- ETL.Tests/: unit tests for pure functions

## How to Run
From the repository root:

```bash
dotnet run --project Main/Main.fsproj
```

Console flow:
- "Read input files from the internet?" (y/n)
	- y: use HTTP URLs (raw GitHub)
	- n: use local files in DataIn/
- Optional filters for status and origin
- "Save to local database (SQLite)?" (s/n)

Outputs:
- DataOut/order_totals.csv: totals by order (total amount and total taxes)
- DataOut/totals_by_month_year.csv: average revenue and taxes by month/year
- DataOut/etl.db: SQLite database (only if chosen)

## Data Pipeline Details
### Extract
- Source selection is interactive (local CSV or HTTP URL).
- CSV loading uses FSharp.Data `CsvFile.Load`.
- Source paths and URLs live in the Reader module.

### Transform
- CSV rows are parsed into domain types (Order, Item) in `HelperFunctions.ConvertCsv`.
- Optional filters are applied for status and origin.
- Orders and items are combined via an inner join in F# by `OrderId`:
	- Implemented in `HelperFunctions.calculation.buildOrderSummaries`.
	- It filters items by allowed order IDs and aggregates totals per order.
- Monthly aggregation computes averages:
	- `CalculateAverageAmountByMonthYear` -> average revenue per month/year.
	- `CalculateAverageTaxesByMonthYear` -> average taxes per month/year.

### Load
- CSV outputs are generated by `Writer` using `StreamWriter`.
- SQLite output is generated by `Writer.writeOrderTotalsToSqlite` using `Microsoft.Data.Sqlite`.

## Libraries Used

## Tests
Run tests with:

```bash
dotnet test ETL.Tests/ETL.Tests.fsproj
```

The test suite maps directly to pure functions in `HelperFunctions`:
- `ConvertCsv.rowToOrder`:
	- Validates mapping of CSV columns to `Order` fields.
	- Checks status and origin decoding.
- `ConvertCsv.CsvToOrder`:
	- Ensures multiple CSV rows become multiple orders.
- `ConvertCsv.rowToItem`:
	- Validates decimal parsing and numeric fields.
- `ConvertCsv.CsvToItem`:
	- Ensures multiple CSV rows become multiple items.
- `calculation.filterStatus`:
	- Keeps only orders with a given status.
- `calculation.filterOrigin`:
	- Keeps only orders with a given origin.
- `calculation.calculeTotalAmount`:
	- Sums item prices * quantity for a single order.
- `calculation.calculateTotalTaxes`:
	- Sums tax * quantity * price for a single order.
- `calculation.buildOrderSummaries`:
	- Validates inner join by order IDs.
	- Checks per-order totals and item counts.
- `calculation.CalculateAverageAmountByMonthYear`:
	- Verifies average revenue per month/year.
- `calculation.CalculateAverageTaxesByMonthYear`:
	- Verifies average taxes per month/year.
